# 🔄 Workflow Guide

## 🌿 Branch Strategy

- main → stable code
- dev → development
- feature/* → new features

---

## 🚀 Development Flow

1. Pull latest code
2. Create feature branch
   git checkout -b feature/xyz

3. Work on feature
4. Commit changes
5. Push branch
6. Create Pull Request

---

## 🧾 Commit Rules

- feat: add new feature
- fix: bug fix
- docs: documentation
- refactor: code improvement

---

## ⚠️ Rules

- No direct push to main
- Test before merging
- Keep commits small
